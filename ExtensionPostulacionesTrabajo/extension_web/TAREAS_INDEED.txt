TAREAS: SOPORTE DE INDEED (solo-extensión, manual)
==================================================

Objetivo
--------
Soportar Indeed como portal en la extensión Firefox "Radar Laboral", de forma
manual (la app NO ingiere Indeed: robots.txt lo prohíbe y hay bot-detection).

Decisiones confirmadas con el usuario
-------------------------------------
- Alcance: Fase A + Fase B (carta + registrar envío en el embudo).
- Metadata de la oferta: JSON-LD JobPosting, con fallback a Open Graph / <title>.
- Dominios: solo Argentina (ar.indeed.com, incluye /m/viewjob).

Hallazgo clave
--------------
La carta del panel es datos.cv.presentacion (texto fijo del perfil, panel.js:130),
NO de la oferta. Por eso "copiar carta" no necesita la base: alcanza con detectar
el id. "Registrar envío" sí: POST /api/extension/enviada exige que la oferta exista
(api.py:868). Por eso Fase B importa la oferta desde la página antes de registrar.

Snippet:

(() => {
  const scripts = [...document.querySelectorAll('script[type="application/ld+json"]')];
  const parsed = scripts.map(s => { try { return JSON.parse(s.textContent); } catch { return null; } });
  const flat = [];
  const walk = v => {
    if (!v || typeof v !== 'object') return;
    if (Array.isArray(v)) return v.forEach(walk);
    if (Array.isArray(v['@graph'])) v['@graph'].forEach(walk);
    flat.push(v);
    Object.values(v).forEach(x => { if (x && typeof x === 'object') walk(x); });
  };
  parsed.forEach(walk);
  const jobs = flat.filter(o => {
    const t = o['@type'];
    return t === 'JobPosting' || (Array.isArray(t) && t.includes('JobPosting'));
  });
  const j = jobs[0];
  console.log(JSON.stringify({
    url: location.href,
    ld_json_scripts: scripts.length,
    jobposting_encontrados: jobs.length,
    title: j?.title ?? j?.name ?? null,
    empresa: j?.hiringOrganization?.name ?? (typeof j?.hiringOrganization === 'string' ? j.hiringOrganization : null),
    datePosted: j?.datePosted ?? null,
    employmentType: j?.employmentType ?? null,
    jobLocation: j?.jobLocation ?? null,
    descripcion_largo: (j?.description || '').length,
    initialData: typeof window._initialData !== 'undefined',
    mosaic_providerData: !!(window.mosaic && window.mosaic.providerData),
  }, null, 2));
  if (j) console.log('--- JobPosting crudo ---', JSON.stringify(j, null, 2));
})();

Resultado -> decision:
- jobposting_encontrados >= 1            -> JSON-LD como fuente primaria.
- 0 pero initialData/mosaic_providerData -> usar window._initialData / mosaic.providerData.
- 0 y ambos false                        -> fallback Open Graph / <title>
  (y evaluar "que el usuario confirme titulo/empresa" en el panel).

Evidencia indirecta: openweb-org/openweb documenta que Indeed embebe
window._initialData, window.mosaic.providerData, __NEXT_DATA__ y
application/ld+json (JobPosting).
